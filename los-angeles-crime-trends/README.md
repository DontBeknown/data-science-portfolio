# Los Angeles Crime Trends

Clean public crime records, track weekly incident counts, and compare reported status and time-of-day patterns across Central, Hollywood, and Pacific in 2023.

[Open the notebook](los-angeles-crime-trends.ipynb) · [Run instructions](../README.md#run-locally)

This notebook adapts a team coursework project and combines its data cleaning and exploratory analysis. The source download selects five fields from the City of Los Angeles public dataset. [Dataset and data dictionary](https://data.lacity.org/d/2nrs-mtv8)
