# Sales Simulation and Order Volume

A seeded Monte Carlo simulation compares printing 20 or 30 units under the same demand. A second analysis uses the Superstore Excel workbook to track daily units ordered and the elapsed calendar days from order to shipment.

[Open the notebook](sales-simulation.ipynb) · [Run instructions](../README.md#run-locally)

The simulation uses a 100-week frequency table from course material. The retail analysis uses a public version of Tableau's fictional Superstore dataset. [Tableau sample data](https://public.tableau.com/app/resources/sample-data) · [Workbook copy](https://github.com/PacktPublishing/Getting-Started-with-Tableau-2019.2/blob/master/Chapter03/Sample-Superstore.xlsx)
