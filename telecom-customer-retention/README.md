# Telecom Customer Retention

Use Kaplan–Meier curves to compare estimated retention by payment method, accounting for customers still active at the end of observation.

[Open the notebook](telecom-customer-retention.ipynb) · [Run instructions](../README.md#run-locally)

The notebook uses the IBM Telco Customer Churn sample dataset. Cohort differences show associations. [Source dataset](https://github.com/IBM/watsonx-ai-samples/blob/master/cpd4.5/data/customer_churn/WA_FnUseC_TelcoCustomerChurn.csv)
